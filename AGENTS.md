# AGENTS.md

This repository contains a static website for Edvin Simenstad.

## Project overview
- The site is plain HTML and CSS.
- The main landing page is `index.html`.
- New pages should be added as standalone HTML files in the repo root, for example `noter.html`.
- Keep styling consistent with the existing site: dark background, warm ivory text, brass accents, serif headings.

## Editing guidelines
- The language of the site is Norwegian.
- Maintain the existing design language and typography.
- Keep navigation consistent between pages.
- Do not add frameworks, build tools, or package dependencies unless explicitly required.
- Preserve accessibility: semantic HTML, clear link text, alt text for images.

## Scope boundaries
- Do not modify unrelated files or generated output.
- Do not commit secrets or personal credentials.
- Keep content factual and consistent with the site’s tone.

## Validation
- Before finishing, verify the page renders correctly in a browser.
- Check that internal links work and that menu navigation remains consistent.
